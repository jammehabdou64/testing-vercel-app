# Separate the Gambian foreign service from foreign missions in The Gambia

Personnel and Foreign Diplomatic Staff are different people, stored apart, and only Personnel can be linked to a login. Gambian Missions (including Home) and Foreign Diplomatic Missions are different places, stored apart. A single person table or a single mission table with a type flag was rejected because the specification gives them different fields, different creators, and different jobs, and merging them would make the foreign registry look like the Gambian foreign service.
